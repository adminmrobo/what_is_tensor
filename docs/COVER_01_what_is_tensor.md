# 표지 지시문 — 01 텐서란 무엇인가 (텐서 연구실 1장)

| 항목 | 내용 |
|---|---|
| 키 · 판 | cover_01 · L (16:9, 가로 1920 이상) |
| 장소 (앵커) | D 생활·현장 — 밤의 연구실 작업대. 연구실 보라 조명이 왼쪽에서 들어옴 |
| 주제 은유 | 작업대 위에 떠 있는 빛나는 숫자 큐브. 아래에서 위로 "구슬 하나 → 구슬 줄 → 판 → 큐브"가 계단처럼 쌓여 큐브로 이어짐 (글자·숫자 없음) |
| 네 캐릭터 포즈 | 박사: 가운데 뒤, 계단 맨 위 큐브를 손바닥으로 가리키며 웃음 / 조수: 오른쪽 앞, 판(격자)을 두 손으로 들고 칸을 세는 표정 / 초파리 연구원: 왼쪽, 오른쪽을 보며 구슬 줄을 돋보기로 의심스럽게 살핌 / 주판봇: 오른쪽, 왼쪽을 보며 주판을 들고 큐브를 올려다봄 |
| 대체 글 (alt) | 밤의 연구실에서 네 캐릭터가 구슬·줄·판·큐브로 이어지는 빛나는 계단을 둘러싼 표지 |
| 앞 표지와 다른 점 | 시리즈 첫 표지. 이후 2장(좌표판)은 벽의 격자 지도, 3장(연산)은 큐브를 돌리고 접는 장면, 4장(분해)은 큐브가 작은 조각들로 풀리는 장면으로 겹치지 않게 |
